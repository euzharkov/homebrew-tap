# euzharkov/tap

Homebrew formulae for tools by [@euzharkov](https://github.com/euzharkov).

```bash
brew install euzharkov/tap/rhow
```

| Formula | What it is |
|---|---|
| `rhow` | Discover how to run and operate any repository. Source: [euzharkov/run-how](https://github.com/euzharkov/run-how) |

Formulae download prebuilt binaries from GitHub Releases and verify their SHA256. The source
of truth for `rhow.rb` is `packaging/homebrew/rhow.rb` in the run-how repository; it is copied
here at release time with the hashes from `SHA256SUMS`.
